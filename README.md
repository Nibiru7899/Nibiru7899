## 🚀 Featured Projects

### 🗣️ Telugu-to-English Speech-to-Speech Translation Pipeline

An end-to-end multimodal pipeline that converts Telugu speech into English speech while preserving the original speaker’s vocal characteristics.

**Technologies:** Python, Whisper, NLLB-600M, QLoRA, YourTTS, ECAPA-TDNN

**Key contributions:**

* Built a modular speech-processing pipeline consisting of transcription, translation, speaker embedding extraction and speech synthesis
* Fine-tuned the NLLB-600M translation model using 4-bit QLoRA
* Reduced model memory requirements while adapting it for Telugu-to-English translation
* Used Whisper for speech recognition and ECAPA-TDNN for speaker representation
* Integrated YourTTS to generate English audio while preserving speaker characteristics

---

### 💊 Pharmaceutical Information and Document Processing System

A document-processing application that extracts information from medicine packaging images and transforms unstructured OCR text into structured pharmaceutical information.

**Technologies:** Python, FastAPI, React.js, Google Cloud Vision, Gemini API

**Key contributions:**

* Built a FastAPI backend for medicine-image ingestion and processing
* Integrated OCR to extract text from pharmaceutical packaging
* Transformed unstructured OCR output into fields such as dosage, side effects and drug interactions
* Added response validation, error handling and fallback processing for incomplete outputs
* Divided the application into independent stages for reliable communication between the frontend, OCR service, language model and API layer

---

### 🌐 Cross-Lingual Sentiment Analysis for Low-Resource Languages

A multilingual sentiment-classification pipeline developed using English and Dravidian-language datasets.

**Technologies:** Python, XLM-RoBERTa, PyTorch, Pandas, NLP

**Key contributions:**

* Processed more than 400,000 multilingual text samples
* Implemented data cleaning, tokenization, label preparation and class balancing
* Fine-tuned XLM-RoBERTa with a custom sentiment-classification layer
* Evaluated model performance using macro F1-score
* Analysed results across different languages and imbalanced sentiment classes
